[ 임베드가 막힌 사이트예요 ]

은(는) 다른 페이지 안에 띄우는 걸 막아 두어서 여기서는 열리지 않을 거예요. 새 탭에서 연 다음 [ 창 ] 모드로 그 탭을 캡처하면 CRT로 볼 수 있어요.

[ 풀 셰이더 켜기 ]

지금은 간단한 스캔라인만 씌워져 있어요. 곡률·블룸·마스크가 들어간 [ 풀 셰이더 ]를 켜려면 화면 공유 권한이 필요해요.

공유 창에서 [ 이 탭 ]을 선택하세요. 이 페이지의 사이트 영역만 캡처되고 외부로 전송되지 않아요.

[ 다른 탭·창·화면에 CRT 셰이더 씌우기 ]

CRT로 보고 싶은 탭이나 창을 고르세요. 조작은 원래 탭에서 하고, 결과는 이 창에서 봐요.

팁: 이 창과 원래 탭을 다른 창으로 나눠 두면 둘 다 보면서 쓸 수 있어요.

브라우저 창
CRT 영역

캡처한 창의 제목 표시줄이나 테두리를 잘라내요. 값은 원본 창의 px이라 창 크기가 바뀌어도 같은 만큼 잘려요.

C 셰이더 켜기/끄기 · S 설정 · F 전체화면 · H 상단바 숨김 (Esc로 다시 표시) · [ ] 이전/다음 프리셋
